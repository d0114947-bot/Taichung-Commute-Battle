# 台中通勤大作戰（Taichung Commute Battle）

這是一個台中通勤模擬遊戲：
- 挑選起點、終點，以及哪一天幾點要到。
- 遊戲會算出開車、騎機車、大眾運輸、走路、騎腳踏車各要多久、花多少錢。
- 每一種方式都會並列「現況」與「何欣純政見版」。
- 點任一方式並確認「開始模擬通勤」，就能看小人沿路通勤，途中會遇到意外事件。
- 最後附上模擬結論。

## 線上試玩

- **GitHub Pages：** https://d0114947-bot.github.io/Taichung-Commute-Battle/
  - 底圖用國土測繪中心的臺灣通用電子地圖，載入失敗時改用 OpenStreetMap。
  - 地址查詢用 Photon、Nominatim。
  - 道路路線用 OSRM，開車、走路、騎腳踏車都沿實際道路。
- **Claude 頁面（claude.ai）：** 改用 TomTom Maps 連接器：
  - 定位地址；
  - 預測指定時刻的開車車流；
  - 查沿途即時路況。

## 何欣純交通政見

- 頁面上的「何欣純交通政見」按鈕會列出 21 項，分成四類：捷運與鐵路、公車與轉運、道路與停車、海線與機場。
- 每一項可以展開查看內容與報導來源；有位置的項目可以在地圖上看示意線。
- 更多政見請見[台中政策島](https://taichung-island.netlify.app/)。

## 「政見版」怎麼算（遊戲假設，不是官方評估）

| 政見 | 遊戲中的假設 |
|---|---|
| 捷運藍線 | 通車：臺中港、沙鹿車站、東海大學、市政府站一帶、臺中車站；時速 35 km，班距 6 分 |
| 橘線延伸台鐵清水站 | 通車：清水車站、臺中機場、臺中車站；時速 35 km，班距 8 分 |
| 公車改革 | 公車班距縮短三分之一 |
| 海線鐵路雙軌化 | 海線台鐵班距減半 |
| 道路瓶頸改善 | 開車、機車的塞車延誤減少 30% |
| 停車政見 | 汽車找車位時間減半，停車費 $40 → $30；機車停車 4 → 2 分 |
| 路口改善 | 走路、騎腳踏車快 5% |
| 4+1 轉運中心 | 公共自行車借還車 3 → 2 分 |
| 公車 App、捷運體檢 | 幽靈公車、捷運故障事件的機率降低 |

## 資料標示

- **真實：** 地點、綠線 18 站與政見端點的座標，查證自 Wikipedia 等來源，2026-10-24。
- **報導依據：** 意外事件（幽靈公車、捷運故障、毒駕）依據新聞報導，事件本身是遊戲模擬。
- **模擬：** 尖峰係數、班距、票價等。
