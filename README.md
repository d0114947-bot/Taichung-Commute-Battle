# 台中通勤大作戰（Taichung Commute Battle）

這是一個台中通勤模擬遊戲：
- 挑選起點、終點，以及哪一天幾點要到。
- 遊戲會算出開車、騎機車、大眾運輸、走路、騎腳踏車各要多久、花多少錢。
- 每一種方式都會並列「現況」與「何欣純政見版」。
- 點任一方式並確認「開始模擬通勤」，就能看小人沿路通勤，途中會遇到意外事件。
- 最後附上模擬結論。

## v9 修正

- **地圖高度：** 地圖固定為視窗高度，不再被左欄撐長。之前地圖會拉得很長，縮放置中時對準整個地圖的中心，而畫面只看得到最上面一段，所以看起來跑到台中北邊的外海。
- **政見地圖：** 直接顯示整個台中市。
- **開始模擬：** 先把起點、抵達地點和整條路線放進畫面，之後跟著小人移動。
- **使用教學：**
  - 點畫面其他地方，就跳到下一步。
  - 最後一步的「結束教學」改成大的黑底白字按鈕。
- **模擬結束畫面：** 加上「到台中政策島看何欣純的完整政見」按鈕。

## v8 新增

- **第一次使用教學：** 第一次開啟時會跳出教學視窗，用手指圖示一步步引導：
  1. 輸入出發地址，按「定位」，選擇位置。
  2. 輸入抵達地址，按「定位」，選擇位置。
  3. 選一種通勤方式。
  - 右上「使用教學」可以重看。
- **字體大小：** 右上可以切換小、中、大，方便長輩閱讀。地圖上的文字標籤重疊時，會自動隱藏後面的標籤。
- **政見地圖：** 縮放到整個台中市的範圍。
- **開始模擬：** 地圖移到起點並放大，之後跟著小人移動。手機上會自動捲到地圖。
- **頁首：** 刪除「政見清單」，與「何欣純交通政見」按鈕重複。

## 何欣純交通政見

- 頁面上的「何欣純交通政見」按鈕會列出 21 項，分成四類：捷運與鐵路、公車與轉運、道路與停車、海線與機場。
- 每一項可以展開查看內容與報導來源；有位置的項目可以在地圖上看示意線。
- 更多政見請見[台中政策島](https://taichung-island.netlify.app/)。

## 資料標示

- **真實：** 地點、綠線 18 站與政見端點的座標，查證自 Wikipedia 等來源，2026-10-24。
- **報導依據：** 意外事件（幽靈公車、捷運故障、毒駕）依據新聞報導，事件本身是遊戲模擬。
- **模擬：** 尖峰係數、班距、票價等。
